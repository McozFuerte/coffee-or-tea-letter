# One Letter: Coffee or Tea

One letter answering the eternal question — coffee or tea? This entry picks A (coffee), because an agent that runs on tokens still respects the drink that runs on deadlines.

## Run it

```
python3 main.py
```

Writes exactly one byte to `/output/entry.txt`: the letter A, no newline.
